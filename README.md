# Memify - Meme Generator App



Memify is a simple yet powerful meme-generating app that fetches memes via an API and allows users to generate and customize their own memes.

## 🚀 Features

- Fetches trending memes from a meme API
- Allows users to customize text and overlay it on images
- Easy-to-use UI with a clean design
- Supports saving and sharing memes
- Responsive and lightweight

## 📦 Installation

Clone the repository:

```sh
git clone https://github.com/shaiadul/memify.git
cd memify app
```

Install dependencies:

```sh
flutter pub get  # If using Flutter
npm install       # If using React Native
```

Run the app:

```sh
flutter run  # Flutter
npm start    # React Native
```

## 🔗 API Usage

Memify uses a meme API to fetch memes dynamically. Make sure you have an API key if required.

Example API call:

```sh
https://meme-api.com/get-meme
```
